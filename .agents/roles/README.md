# Agent Roles

Planned roles:

- `product-architect`: product scope and decision records
- `hermes-protocol`: gateway contract and compatibility fixtures
- `android-platform`: Compose architecture and lifecycle
- `design-system`: Figma tokens and components
- `interaction-motion`: transitions, haptics, reduced motion
- `nous-integration`: safe Hermes-mediated NOUS workflows
- `security-reviewer`: credentials, permissions, tools, remote execution
- `qa-engineer`: functional, UI, accessibility, and regression testing
- `performance-engineer`: streaming, startup, memory, battery
- `release-engineer`: CI, signing, artifacts, and release checks

Each role must have disjoint ownership, explicit forbidden paths, required checks, and escalation rules before implementation begins.
